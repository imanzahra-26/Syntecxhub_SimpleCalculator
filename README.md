# Syntecxhub_SimpleCalculator

A simple command-line calculator built in Python as part of the Syntecxhub internship program.

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear function to reset result to 0
- ✅ Input validation (rejects invalid numbers and operators)
- 🛡️ Divide-by-zero error handling
- 🔁 Menu-driven loop for repeated calculations

## 🛠️ Technologies Used

- Python 3
- No external libraries

## 🚀 How to Run

1. Make sure Python 3 is installed
2. Open a terminal in this folder
3. Run:
```bash
python calculator.py
